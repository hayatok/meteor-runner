# メテオランナー ― 星屑航路

夕闇の星間航路を配達ドローン「ピコ」が駆け抜ける、3レーン式 3D エンドレスランナー。

- 企画・指示： Muse（上田美咲）
- 実装： Codex
- アセット： Blender で新規作成
- 設計書： [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)

## 遊び方

- ←→ / A・D、または左右スワイプ： レーン移動
- ↑ / W / Space、または上スワイプ： ジャンプ（結晶床を越える）
- ↓ / S、または下スワイプ： ダイブ（バリアの下を抜ける）
- 隕石はレーン移動で回避。ギリギリですれ違うとニアミスコンボでスコア倍率アップ。

## 開発

```bash
npm install
npm run dev
npm run build
```
