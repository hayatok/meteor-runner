# メテオランナー v2 アップデート仕様

基本設計は `docs/GAME_DESIGN.md`。本書が v2 の追加・変更点の正。
承認済みの上書き（ニアミス横距離 2.6m）は維持する。

## A. 仕上げ修正

1. **マグネット終了時の星屑の跳ね修正**： 星屑ごとに「本来の軌道位置」と「引寄せオフセット」を
   分けて持ち、マグネット無効時はオフセットを滑らかに 0 へ戻す。位置が不連続に跳んではいけない。
2. **空フェーズを設計書 §1 通りに**： 4フェーズの区間は 夕 0–500m / 夜 500–1500m /
   深夜 1500–2500m / 夜明け 2500–3500m、以降 3500m サイクル。各区間の最後の 20% で
   次フェーズへ滑らかに補間。色は基調色（藍 #232a52、ティール #2ec4b6、夕光 #ff8c42、
   クリーム #f5ead9、星屑黄 #ffd94d）と、藍の明暗シェードのみを使う。紫などの外色は禁止。
3. **当たり判定を機体幅に合わせる**： プレイヤー半幅 0.5 と障害物半幅の和で判定する。
   半幅は meteor 0.8 / asteroid_b 1.0 / crystal 0.9 / barrier 1.0。
   つまり閾値は 1.3 / 1.5 / 1.4 / 1.5。ジャンプ／ダイブでの回避条件は従来通り。

## B. 手触り強化

1. **FOV キック**： 視野角は速度 18→46 m/s に応じて 62→74 度へ滑らかに変化。
2. **スピード線**： 速度 30 m/s 以上で、カメラ脇を流れる光の線（プールした LineSegments か
   ポイント列）を表示。速度で量と速さが増える。
3. **ニアミス演出**： 小シェイク（振幅 0.08、0.15 秒）＋ HUD 付近に「NEAR MISS ×{コンボ}」の
   ポップ表示（フェードアウト）。
4. **星屑パーティクル**： 取得時に発光する小粒子 約10 個が散って消える（プール管理）。
5. **衝突演出**： 大シェイク（振幅 0.3、0.4 秒）＋ 0.6 秒間だけ timeScale 0.25 の
   スローモーション、その後に結果画面。

## C. 音（WebAudio 合成のみ、外部ファイル禁止）

- 新規 `src/audio.js`。AudioContext はユーザージェスチャ（出発ボタン）で生成・再開する。
- BGM： 疾走感のあるシンセのループ（ベースの脈動＋短いアルペジオ、短調、約132 BPM、音量控えめ）。
- 効果音： 星屑取得（コンボで音程上昇）、ニアミス（短い風切り）、ジャンプ（上昇スイープ）、
  ダイブ（下降スイープ）、シールド取得、マグネット取得、ゲート通過（チャイム）、
  衝突（ノイズ＋低音）、UI クリック。
- ミュート切替ボタンと M キー。状態は localStorage に保存。デフォルトは音あり
  （ただし再生開始はジェスチャ後）。

## D. やり込み

1. **ランク表示**： 結果画面にスコアランクを大きく表示。S ≥ 8000 / A ≥ 4500 / B ≥ 2500 /
   C ≥ 1200 / D はそれ未満。
2. **ランミッション**： 開始時にプールから 3 件をランダム表示（例： ニアミス5回、星屑40個、
   800m到達、ゲート8回通過、シールド取得、コンボ ×2.0 到達）。達成ごとにトースト表示と
   +300 点ボーナス。結果画面に達成ミッションとボーナス合計を表示する。
