# メテオランナー v3 演出強化仕様（派手版）

基本設計は `docs/GAME_DESIGN.md`、v2 は `docs/UPDATE_V2.md`。本書は演出のみの追加仕様。
ゲームバランス（速度・生成・スコア式）は変えない。小浜の指示により「もっと派手に」が方針。

## 1. 移動・速度

- **トレイル＆スラスター**： ドローン後方に光のトレイル（速度で長さと明るさ増）、
  スラスター炎は速度で伸縮し、ダッシュ感のある明滅。色はティール→高速でゴールド寄り。
- **カメラワーク**： レーン移動でカメラがロール＋軽く遅れて追随。高速時は微振動。
  ジャンプ頂点で一瞬だけカメラが引く。
- **星屑ダスト**： 常時、細かい光の粒が手前へ流れ、速度感を出す（プール、密度は速度連動）。

## 2. アクション

- **カウントダウン**： 開始時に大きな「3・2・1・GO!」がズームイン表示＋ライザー音。
  GO でスラスター全開のフラッシュ。
- **ジャンプ／着地／ダイブ**： 着地でデッキに二重の波紋リング＋粉塵バースト。
  ダイブ中は機体周りに風切り線。ジャンプ開始で小さなリング。
- **星屑チェーン**： 連続取得（2秒以内の連続）で「CHAIN ×n」ポップが段々大きく・金色に。
  取得した星屑は一瞬光の筋を残して消える。チェーンが切れると小さく表示して終了。

## 3. イベント

- **ゲート通過**： 全画面の放射フラッシュ＋衝撃波リングが広がり、画面端がティールに光る。
  チャイムはアルペジオで豪華に。
- **フェーズ到達**： 500/1500/2500m で「NIGHT」「DEEP NIGHT」「DAWN」の巨大バナーが
  流れ、空の色が波のように遷移し、星が一斉に瞬く。
- **フィーバー**： コンボ倍率 ×3.0 到達で FEVER 突入バナー。デッキの発光ラインが脈動し、
  トレイルが金色、BGM に追加レイヤー（高音アルペジオ）が乗る。コンボが切れたら終了バナー。
- **アイテム取得**： シールド／マグネット取得で拡大リング＋ドローンにオーラ。
  マグネット中は周期的に磁力リングを表示。シールド消費時はバリアが割れる表現（破片＋音）。
- **衝突**： 白フラッシュ＋ドローンが光る破片になって飛散＋衝撃波リング＋大きな爆発音、
  その後 v2 のスローモーションへ。

## 4. 結果・タイトル

- **結果画面**： スコアがカウントアップ（ティック音付き）、ランクはスタンプのように
  叩きつけるアニメーション＋小シェイク、S/A ランク時は星屑の紙吹雪。
- **タイトル**： ロゴが発光パルス、ドローンがアイドルで上下動＋ライト点滅、
  背景のゲートをくぐる演出をゆっくりループ。

## 5. 音の追加（WebAudio 合成のみ）

- カウントダウンのライザーと GO の解放音、フィーバー突入ジングル、ゲートのアルペジオ、
  シールド割れ、爆発の重低音、結果カウントアップのティック、ランクスタンプ音。

## 6. パフォーマンス規律（必須）

- 粒子・リング・線は全てプール管理し、同時上限を決める（粒子 300、リング 12、トレイル 1 系統）。
- フレーム時間が 24ms 超えが続いたら粒子量を自動で半減する適応品質を入れる。
- pixelRatio 最大 2 は維持。スマホで 60fps を目標とし、演出でゲームプレイを邪魔しない
  （ポップ類は HUD 領域に寄せ、視界中央を塞がない）。
