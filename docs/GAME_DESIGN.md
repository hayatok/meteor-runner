# メテオランナー ― 星屑航路（ほしくずコリドー）設計書

企画・指示： 上田美咲（Muse） / 実装： Codex / プロジェクト管理： このリポジトリの Issue

## 1. 世界観

遠い未来、隕石帯を切り開いて作られた古代の星間航路「星屑航路」。夕闇に染まる宙を、
配達ドローン「ピコ」が荷物を背負って全速力で駆け抜ける。航路は発光ラインの入った
ダークなデッキ、周囲には結晶を宿す隕石とティールの星雲が漂う。

### ビジュアルアイデンティティ（厳守）
- 基調色： 深い藍 `#232a52`（宙） / ティール `#2ec4b6`（星雲・発光ライン） /
  夕光オレンジ `#ff8c42`（スラスター・バリア） / クリーム `#f5ead9`（機体） /
  星屑イエロー `#ffd94d`（発光）
- 空は距離でフェーズ変化： 0–500m「夕」→ 500–1500m「夜」→ 1500–2500m「深夜」→
  2500m–「夜明け」、以降はサイクル。背景色・フォグ・ライト色を滑らかに補間する。
- 全アセットはこの世界専用に Blender で新規作成（`public/models/*.glb`）。
  読み込めない場合は簡易ジオメトリにフォールバックして必ず遊べること。

## 2. ゲーム概要

- ジャンル： 3レーン式 3D エンドレスランナー（Three.js / Vite）
- 目的： できるだけ長く生き残り、距離とスコアを伸ばす。ベスト記録は localStorage。
- プレイヤー： ドローン「ピコ」。ホバーで浮遊し、常に前進（ワールド側が流れる実装でも可）。

## 3. 操作

- キーボード： ←→ または A/D = レーン移動 / ↑・W・Space = ジャンプ /
  ↓・S = ダイブ（急降下＋低姿勢）
- タッチ： 左右スワイプ = レーン移動 / 上スワイプ = ジャンプ / 下スワイプ = ダイブ /
  画面左右タップでもレーン移動可
- レーンは x = -2.2 / 0 / 2.2 の3本。レーン移動は約0.12秒でスムーズに補間し、機体が傾く。

## 4. ゲームシステム

- 速度： 初速 18 m/s、毎秒 +0.35、上限 46 m/s。
- 障害物（3種）：
  1. **隕石 (meteor)**： レーンを塞ぐ岩。レーン移動で回避。
  2. **結晶床 (crystal)**： 低い結晶の床。ジャンプでのみ回避。
  3. **エネルギーバリア (barrier)**： 頭上の梁。ダイブ（低姿勢）でのみ回避。
- 生成ルール（最重要）： 同一 z 付近で3レーン全てを「同種の回避要求」で塞がない。
  必ず最低1レーンは素通りできるか、ジャンプ／ダイブで全レーン抜けられる構成にすること。
  生成間隔は速度に応じて調整し、序盤は疎に、終盤は密にする（ただし抜け道は常に保証）。
- アイテム：
  - **星屑 (shard)**： 列や弧を描いて配置。取得でスコア加算。マグネット中は吸着。
  - **シールド (shield)**： 1回だけ衝突を無効化（機体にバリア表示）。
  - **マグネット (magnet)**： 6秒間、周囲の星屑を引き寄せる。
- **ニアミスコンボ**： 障害物と衝突せずに近距離（横 1.2m 以内）ですれ違うとコンボ +1。
  スコア倍率は min(1 + コンボ数 × 0.1, 8) 倍。衝突（シールド消費含む）でコンボリセット。
- スコア： 距離 1m = 1点、星屑 1個 = 25点 × 倍率。HUD にスコア／距離／コンボ倍率／速度を表示。
- ゲームオーバー： 障害物に衝突（シールドなし）。結果画面に距離・スコア・ベスト・
  ニアミス回数を表示し、リスタートボタンで即再走。
- 演出： ゲート（gate）を定期的にくぐる（通過時に軽いフラッシュと +50 点）。
  500m フェーズごとに空の色が変わる。タイトル画面に世界観の短い導入文とベスト記録。

## 6. 技術要件

- Vite + Three.js（npm）。`vite.config` の `base: './'` を必ず設定し、
  モデル URL は `import.meta.env.BASE_URL` 基準の相対パス（GitHub Pages のサブパス対策）。
- オブジェクトプールで障害物・星屑を再利用し、GC を抑える。pixelRatio は最大 2。
- 一時停止： タブが非表示になったら自動ポーズ。ポーズボタン（Esc / 画面ボタン）も用意。
- WebGL 初期化に失敗したら画面にエラーメッセージを表示（無言で真っ暗にしない）。
- 音は v1 では入れない（将来 Issue で追加）。
- `npm run build` が成功し、`dist/` をサブパス配信しても全 GLB が 200 で読めること。
